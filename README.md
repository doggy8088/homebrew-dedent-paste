# homebrew-dedent-paste

Homebrew tap for [dedent-paste](https://github.com/doggy8088/dedent-paste): paste clipboard text with the common indentation removed.

## Install

```sh
brew tap doggy8088/dedent-paste
brew trust doggy8088/dedent-paste
brew install dedent-paste
```

Homebrew 6 and later refuse to load formulas from third-party taps until you run `brew trust` on the tap once. On older Homebrew versions the `brew trust` step is not needed and can be skipped.

## Upgrade

```sh
brew upgrade dedent-paste
```

## Uninstall

```sh
brew uninstall dedent-paste
brew untap doggy8088/dedent-paste
```

## Set up the hotkey

Homebrew installs the `dedent-paste` binary only. After `brew install` finishes it prints a reminder to finish the Karabiner-Elements setup:

```sh
brew install --cask karabiner-elements   # if you do not have it yet
dedent-paste --install
```

`dedent-paste --install` backs up your Karabiner profile, then adds an `Option+V` rule that runs the Homebrew-installed binary. Run `dedent-paste --uninstall` to remove it again. If nothing happens when you press `Option+V`, allow Karabiner-Elements under System Settings > Privacy & Security > Accessibility. See the [dedent-paste README](https://github.com/doggy8088/dedent-paste#macos) for details.

## How this tap is updated

The formula in [`Formula/dedent-paste.rb`](Formula/dedent-paste.rb) is generated by [cargo-dist](https://opensource.axo.dev/cargo-dist/) from the [dedent-paste release workflow](https://github.com/doggy8088/dedent-paste/blob/main/.github/workflows/release.yml). Every dedent-paste release pushes an updated formula here automatically. Do not edit the formula by hand.

cargo-dist cannot emit Homebrew `caveats`, so the [`Add Homebrew caveats`](.github/workflows/caveats.yml) workflow runs [`scripts/add-caveats.py`](scripts/add-caveats.py) after each formula push and appends the Karabiner-Elements reminder. The script is idempotent and skips versions older than 0.3.3, which do not support `--install`. To change the reminder text, edit the script.
