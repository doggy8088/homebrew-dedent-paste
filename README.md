# homebrew-dedent-paste

Homebrew tap for [dedent-paste](https://github.com/doggy8088/dedent-paste): paste clipboard text with the common indentation removed.

## Install

```sh
brew tap doggy8088/dedent-paste
brew trust doggy8088/dedent-paste
brew install dedent-paste
```

Homebrew 6 and later refuse to load formulas from third-party taps until you run `brew trust` on the tap once. On older Homebrew versions the `brew trust` step is not needed and can be skipped.

## Upgrade

```sh
brew upgrade dedent-paste
```

## Uninstall

```sh
brew uninstall dedent-paste
brew untap doggy8088/dedent-paste
```

## Set up the hotkey

Homebrew installs the `dedent-paste` binary only. To trigger it with `Option+V` on macOS, add a Karabiner-Elements rule that runs the Homebrew binary. See the [dedent-paste README](https://github.com/doggy8088/dedent-paste#macos) and the example rule in [`examples/macos/paste-dedent-plain-text.json`](https://github.com/doggy8088/dedent-paste/blob/main/examples/macos/paste-dedent-plain-text.json), replacing the `shell_command` path with:

```text
/opt/homebrew/bin/dedent-paste
```

(Use `/usr/local/bin/dedent-paste` on Intel Macs.)

## How this tap is updated

The formula in [`Formula/dedent-paste.rb`](Formula/dedent-paste.rb) is generated by [cargo-dist](https://opensource.axo.dev/cargo-dist/) from the [dedent-paste release workflow](https://github.com/doggy8088/dedent-paste/blob/main/.github/workflows/release.yml). Every dedent-paste release pushes an updated formula here automatically. Do not edit the formula by hand.
